# ForestEar — live demo script (~10 minutes)

Preparation (once): `make data dataset backgrounds cache train export eval`
and keep a terminal for the backend.

## 0. Clean slate (1 min)

```bash
rm -f data/backend.db data/edge_queue_*.db
rm -rf data/sim
make backend          # terminal 1 — http://127.0.0.1:8000
```

Open the dashboard in a browser. The editorial preloader lifts into the
velvet masthead; the map shows zero nodes ("the canopy is quiet" empty
states).

> Speak-along: everything you see is produced by the code in this repo —
> nodes, audio, models and metrics. Nothing is mocked.

## 1. Single-node sanity — laptop mic or file replay (2 min)

```bash
make agent-file F=data/dataset/   # or: make agent-mic
```

One node appears on the map with a pulsing pin; live per-model score bars
and the streaming spectrogram animate at 2 hops/s; the event ticker runs.
Point out: the node heartbeats carry lat/lon, CPU and battery (psutil).

## 2. Chainsaw approach — persistence + escalation (2 min)

```bash
make demo            # scenario chainsaw_approach, 4 nodes
```

Narration beats:

1. A distant chainsaw enters the area; nodes begin detecting it hop by hop.
2. **k-of-n**: single windows do not alert; 3-of-5 do — the first WARNING
   lands with its `3/5` persistence tag in the feed.
3. The saw runs for >4 s: **sustained chainsaw escalates to CRITICAL** —
   a red event crosses the ticker.
4. Expand a feed row: the per-model drawer shows every model's score for
   that window (M1–M9) — this is the ensemble's reasoning, exposed.
5. Telegram dry-run line prints in the backend terminal (message text the
   ranger would receive).

## 3. Thunderstorm — the veto must hold (1.5 min)

```bash
make demo-thunder
```

Thunder cracks over the nodes. Gunshot scores may tick up, but M5 flags
thunder ≥ 0.6 and the decision engine **suppresses the alert** — the
suppressed event shows in the veto feed with its reason string. Zero
false gunshot alerts is the pass condition.

## 4. Rainstorm + chainsaw — the veto must NOT over-hold (1.5 min)

```bash
../.venv/bin/python simulator/run_nodes.py --scenario rainstorm_with_chainsaw
```

Rain is heavy but a real saw is running: WARNING/CRITICAL chainsaw events
still fire (the veto only gates low-confidence gunshots). This asymmetry
is deliberate and unit-tested.

## 5. Gunfire burst — TDOA localisation (1.5 min)

```bash
make demo-gunfire
```

3+ nodes hear the burst within a 6 s window: the correlator solves
time-difference-of-arrival and the map draws a **position + uncertainty
circle** (green). The estimates tab / feed shows the method (`tdoa`),
nodes used and radius. With 2 nodes it degrades honestly to a bearing
band; with 1 node to a coarse radius (never a fake position).

## 6. Offline resilience (1 min)

Stop the backend (Ctrl-C in terminal 1), run any demo again — events queue
into `data/edge_queue_*.db` (show the file size growing). Restart the
backend; the queue flushes automatically and the dashboard catches up.
(The offline-queue flush is also unit-tested.)

## 7. Biodiversity + analytics (1 min)

- Biodiversity tab: species list in script type with counts, mean
  confidence and the hourly activity chart — M8 BirdNET duty-cycled at
  10 %, so it costs almost nothing.
- Analytics tab: click **Load** next to each report — per-model metrics,
  confusion matrix, calibration, robustness, ablation bars. Every number
  comes from `reports/*.json` generated by `make eval` on the held-out
  test split.
- `/export/events.csv` downloads the full event log for the report.

## Talking points (probable questions)

- *Where do the numbers come from?* — `make eval` only; the README lists
  assumptions (missing US8K clips, FSD50K subset, Python 3.12 deviation).
- *Why not one big model?* — the ensemble separates concerns: a frozen
  generalist (M1), cheap specialists, an open-set tripwire (M6), a
  weather veto (M5) and a calibrated meta-decision (M9) whose feature
  groups are ablated in `reports/ablation.json`.
- *Privacy?* — speech is never stored or transmitted; clips only for
  non-speech classes; telemetry is fire-and-forget.
- *What happens on a Pi?* — `make export` benchmarks TFLite latency;
  int8 for M2/M5, float16 elsewhere; the agent skips heavy models below
  the silence threshold.
- *3 nodes only?* — TDOA is two-fold ambiguous with exactly 3 nodes; the
  correlator detects the ambiguity and inflates the uncertainty radius
  instead of lying (4+ nodes are unique).
